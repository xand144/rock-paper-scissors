# rock-paper-scissors

This is my first JavaScript project that I completed for the Odin Project. The aim was to create a rock paper scissors game that can be played without a GUI, using the browser console. I also added alerts alongside console outputs so that the game can be played without opening the console.

I later modified this project, replacing the prompt inputs and console outputs with a GUI, which allows the game to be played by clicking buttons, with the score and results dynamically updated on the page.

This project gave me valuable practice with the fundamentals of JavaScript, such as variables, operators, conditionals, function declarations, and anonymous functions.
